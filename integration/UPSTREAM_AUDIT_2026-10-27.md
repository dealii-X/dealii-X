## Scientific network choice

[Open question #41](https://github.com/dealii-X/dealii-X/issues/41) compares full ADAVN and reduced ADAN56 for the current model, without deciding. The available complete importer covers the arterial component of ADAVN 2023; constitutive venous support does not supply the entire venous topology/closed-loop circulation. Geometry, physiological interfaces, closure/calibration, observables and computational validation must determine the choice.

## Important integration gap

MetricFlowX PR [#65](https://github.com/luca-heltai/metric-flow-x/pull/65) removed `Write terminal CSV files` and the per-terminal output layout used by the currently pinned adapters. Adopting current main requires the new `Output terminal CSV file` setting plus boundary-ID demultiplexing. Revalidate failure/coverage gates with the new IDA guard and native initialization. Existing validated old-pin evidence remains historical evidence; it is not a current-main integrated run.

The 4C oxygen fix is upstream ([4C #2360](https://github.com/4C-multiphysics/4C/pull/2360)), but the old integration pin still uses a retained patch. Its retirement requires the pin/build/regression work in central #22/#31/#34. Platform PR [#239](https://github.com/2listic/dealiiX-platform/pull/239) remains stacked outside main; PSBLAS-EXT PR [#2](https://github.com/sfilippone/psblas3-ext/pull/2) remains open. No additional central issue is closed by this audit.
